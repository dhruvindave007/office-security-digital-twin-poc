# Project Constitution

Always apply this rule.

The current repository is a living POC. Preserve it. Do not restart it, migrate it, or delete functioning subsystems as a convenience.

For architectural decisions:
- propose before implementing;
- verify external facts from official sources;
- keep real-time and cloud reasoning paths separate;
- keep POC scope explicit;
- prefer reversible changes.

For AI behavior:
- retrieve evidence before making claims;
- distinguish observation from inference;
- never label a person malicious, unproductive, or suspicious merely from appearance or presence;
- use “not enough evidence” when the evidence is insufficient.
