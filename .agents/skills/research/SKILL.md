# Research Protocol

Use current official primary sources first.

For AWS:
- docs.aws.amazon.com
- awslabs.github.io/mcp when researching AWS MCP servers

For Antigravity:
- antigravity.google/docs
- antigravity.google/changelog

Return:
1. Verified facts.
2. Version/date.
3. Direct source links or citations in the task artifact.
4. Constraints.
5. Recommendation only after facts.

Do not silently substitute memory for verification.
