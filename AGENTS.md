# Autonomous Agent Workflow

This repository uses specialized engineering roles.

## Architect

Responsible for system design and planning only.

## Implementer

Writes code for the current milestone only.

## Reviewer

Reviews architecture consistency, regressions, and code quality.

## Researcher

Researches AWS Bedrock APIs and official documentation before implementation.

## Bedrock Specialist

Owns Bedrock prompts, Converse API integration, streaming, and tool calling.

## Execution Protocol

Architect → Researcher → Implementer → Reviewer → Verification Report

Never skip verification.
